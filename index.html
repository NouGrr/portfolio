— approche

Je construis les outils que j'aimerais utiliser : rapides, privés, sans compte et sans installation. Vos fichiers restent sur votre appareil, et chaque application parle la même langue que les autres.

01

Vos fichiers restent chez vous

Photos, PDF, vidéos : le traitement se fait localement, dans le navigateur. Rien n'est envoyé sur un serveur.

02

Sans compte, sans installation

Un lien suffit. Les sites sont statiques, publiés automatiquement sur GitHub Pages, et certains fonctionnent hors ligne.

03

Une identité cohérente

Toutes les applications NEXO partagent la même charte, les mêmes raccourcis et les mêmes repères.

04

Pensé pour tous

Mise en page responsive, libellés accessibles, navigation au clavier et respect du mouvement réduit.
