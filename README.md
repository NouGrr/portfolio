## Fonctionnalités

- Écran de chargement où le logo se dessine trait par trait
- Fond de lignes topographiques animé, qui s'allume autour de la souris
- Galerie de projets à cadres : dévoilement au survol, fiche détaillée au clic, colonnes en parallaxe
- Animations de titres : balayage, écriture manuscrite, lettres à largeur variable, lettres brouillées
- Thème clair / sombre, mise en page responsive
- Respect du réglage « réduire les animations » du système

## Technologies

HTML, CSS et JavaScript, sans framework, sans dépendance et sans étape de compilation. Le fond est dessiné en Canvas 2D. Les polices Archivo, Caveat et JetBrains Mono viennent de Google Fonts.

```
index.html      contenu du site
styles.css      styles et animations
script.js       interactions et effets
assets/         favicons
```

## Lancer en local

```sh
python3 -m http.server 4173
```

Ouvrir ensuite http://localhost:4173.

## Publication

Le site est publié avec GitHub Pages, depuis la racine de la branche `main`. Chaque push met le site à jour.
